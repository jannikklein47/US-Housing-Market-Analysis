# US Housing Market Analysis

[Kaggle URL](https://www.kaggle.com/datasets/ahmedshahriarsakib/usa-real-estate-dataset)

Pip dependencies sind via requirements.txt zu installieren
Eine .env Datei mit der Variable FBI_API_KEY ist erforderlich. Dieser ist bei der FBI Crime Datenquelle zu erlangen.

Zuerst load_data.py ausführen
Danach extend_dataset.py ausführen
Zum Schluss export_final_csv.py ausführen

Der finale Datensatz liegt in data/final/final_dataset.csv
